# Task 28 — Membangun statistik membaca

**Tujuan:** Menyajikan statistik pribadi dari aktivitas yang tersimpan.

**Prasyarat:** Task 22, 23, dan 26–27.

**Pekerjaan:**
- Definisikan “buku dibaca” berdasarkan status `READ` dan dokumentasikan definisi ini.
- Hitung jumlah selesai, review, reading list per status, dan tren yang dapat didukung data.
- Sajikan ringkasan/chart dengan Recharts bila sesuai.

**Kriteria penerimaan:**
- Statistik berasal dari query database dan terisolasi per user.
- Perubahan reading list/review tercermin tanpa nilai hard-coded.
- Chart memiliki label, aksesibilitas, dan fallback data kosong.

**Verifikasi:** Bandingkan statistik UI dengan query source data pada beberapa fixture.
