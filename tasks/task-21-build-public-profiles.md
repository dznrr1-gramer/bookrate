# Task 21 — Membangun profil publik

**Tujuan:** Menampilkan profil dan aktivitas pengguna yang memang ditetapkan publik.

**Prasyarat:** Task 15–17.

**Pekerjaan:**
- Buat halaman profil publik dengan nama, avatar, bio, serta review/aktivitas yang diizinkan.
- Tentukan dan patuhi aturan privasi data; jangan tampilkan email atau informasi autentikasi.
- Berikan state profil tidak ditemukan atau tidak tersedia.

**Kriteria penerimaan:**
- Data privat tidak dikembalikan ke client atau dirender.
- Profil publik dapat dibuka Guest.
- Informasi aktivitas konsisten dengan policy privasi produk.

**Verifikasi:** Uji respons/HTML untuk memastikan field privat tidak bocor.
