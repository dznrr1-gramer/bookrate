# Task 22 — Membangun profil dan dashboard pengguna

**Tujuan:** Memberi pengguna pusat untuk mengelola profil dan melihat aktivitas membaca.

**Prasyarat:** Task 15–17, 26–27 (dashboard dapat dirakit setelah sumber aktivitas tersedia).

**Pekerjaan:**
- Buat halaman edit profil dan dashboard yang hanya dapat diakses pemilik akun.
- Tampilkan total buku dibaca, review, reading list, favorit terbaru, aktivitas, dan review terbaru.
- Terapkan loading, error, dan empty state; gunakan Recharts hanya untuk chart yang memberi insight.

**Kriteria penerimaan:**
- Semua data dashboard dibatasi pada user aktif.
- Total dihitung dari data sumber yang didefinisikan, bukan nilai hard-coded.
- Layout nyaman di desktop dan mobile.

**Verifikasi:** Uji dua akun terpisah dan pastikan data satu akun tidak muncul pada akun lain.
